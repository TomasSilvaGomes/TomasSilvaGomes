## Featured Projects

* [Deepfake Face Detector](https://github.com/TomasSilvaGomes/Deepfake-Face-Detector) — Multimodal Deepfake Detection (Thesis Project)
Bachelor's thesis project, designed and built end-to-end: a multimodal system that detects and explains synthetic facial manipulations through three stages — a texture-artifact classifier, spatial explainability via CLIP heatmaps and facial segmentation, and a logistic regression fusion layer combining all signals into a final verdict with an automatically generated natural-language report.

  **Stack:** Python, PyTorch, Streamlit

* [MNIST XAI](https://github.com/TomasSilvaGomes/Projeto_Int_Causalidade) — Interpretability Methods for CNNs
Comparative study of explainability techniques (Integrated Gradients, DeepLift, Saliency, Guided Grad-CAM) applied to a convolutional network trained on MNIST, evaluating how each method attributes a prediction back to input pixels.

  **Stack:** Python, PyTorch, Captum

* [Biometric Explanator](https://github.com/TomasSilvaGomes/Prompt-Engineer) — Biometric Verification with CNN + LLM Justification
Ocular biometric verification system: a CNN (Keras) decides whether two eye images belong to the same person, paired with a multimodal LLM (CLIP embeddings + InternVL-Chat) that generates a plain-language justification for the decision.

  **Stack:** Python, Keras, CLIP

* [Extract Transform and Load Twitch Streamers](https://github.com/TomasSilvaGomes/projeto_ETL) — Twitch Data Pipeline & Visualization
Automated ETL pipeline that pulls top-streamer data from the Twitch API every two days, cleans and formats it, loads it into SQL Server, and feeds a Looker Studio dashboard.

  **Stack:** Python, Pandas, SQL Server

* [Smart City](https://github.com/TomasSilvaGomes/Projeto_BD) — Smart City Relational Database
Relational database design for a "smart city" scenario (public transport, traffic, environmental sensors, parking), modeled in SSMS with ER diagrams normalized to 3NF, plus a Python/Tkinter app for CRUD operations and validation triggers.

  **Stack:** SQL Server, Python (Tkinter)

* [Scraping](https://github.com/tiagomfmarques/scraping) — Reddit Scraping & Dashboard
Scrapes r/championsleague via the Reddit API, stores posts in CSV and SQL Server, and serves a FastAPI web interface for searching content and viewing real-time stats.

  **Stack:** Python, FastAPI, SQL Server
